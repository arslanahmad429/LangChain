# LangChain Experiments & Conversational Chatbots

A repository containing LLM agent implementations, LangChain chain experiments, and conversational chatbot prototypes.

---

## Highlights

- **MyChatbot**: Custom conversational chatbot interface powered by LangChain and LLMs.
- **RAG & Prompt Engineering**: Modular prompt chains, memory components, and vector store retrieval examples.

---

## Setup & Execution

```bash
# Activate virtual environment
source venv/bin/activate  # Linux/macOS
.\venv\Scripts\Activate.ps1 # Windows

# Run chatbot
python MyChatbot/main.py
```
